# Website Pembelajaran Kelas XI Hang Jebat 2026/2027

Website belajar online: materi per bab, video YouTube, kuis interaktif dengan nilai otomatis, daftar tugas, dan progres belajar siswa.

## Cara mengubah isi
Semua isi ada di **`data.js`**. Buka file itu di GitHub, klik ikon pensil (Edit), ubah teksnya, lalu klik **Commit changes**. Website akan ter-update otomatis dalam 1–2 menit.

## Cara menerbitkan (sekali saja)
Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
